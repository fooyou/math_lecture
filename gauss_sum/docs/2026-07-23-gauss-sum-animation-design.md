# 设计文档：高斯求和 / 等差数列可视化动画 (写实科技风)

## 1. 概述
本动画旨在通过写实科技风的几何拼接，向小学生直观展示高斯求和公式 `S = n(n+1)/2` 的推导过程。核心思路是：将 1+2+...+n 的求和看作一个**阶梯形**，再用一个**镜像副本**拼成矩形，一眼看出求和公式。

## 2. 视觉风格
- **背景**：深色调（深空灰/藏青），延续现有项目的科技实验室风格。
- **原始阶梯**：冷色调（科技蓝/青色），带辉光。
- **镜像副本**：暖色调（金色/橙色），与原始阶梯形成对比。
- **标注文字**：白色/淡色，极简字体。
- **KaTeX 公式**：黄色/青色高亮，带辉光。

## 3. 动画环节

### 第1阶段：阶梯构建 (progress 0.0 – 0.25)
- 画面左侧/底部起始，从左到右逐列"生长"出方块堆叠。
- 第 k 列有 k 个方块，形成 1, 2, 3, ..., n 的阶梯形。
- 每列顶部标注当前数字。
- 左上角显示文字："S = 1 + 2 + 3 + ... + n"

### 第2阶段：镜像拼接 (progress 0.25 – 0.60)
- 一个暖色调（金色）的**镜像阶梯**从上方滑入画面。
- 镜像阶梯旋转 180° 后，与原始阶梯严丝合缝地拼合成一个 **n × (n+1) 的矩形**。
- 拼接瞬间发光特效，强调"正好契合"。
- 矩形下方标注：`宽 = n`，`高 = n+1`，`面积 = n × (n+1)`

### 第3阶段：公式推导 (progress 0.60 – 1.00)
- 矩形的高亮消失，原始阶梯（蓝色部分）重新突出显示。
- 文字提示："原来的阶梯是矩形的一半"
- KaTeX 公式逐步显示：
  ```
  矩形面积 = n × (n+1)
  S = ½ × 矩形面积 = ½ × n × (n+1)
  ```
- 当 n=100 时：S = 100×101÷2 = 5050
- 最终公式高亮：`S = n(n+1)/2`

## 4. 技术实现要点
- **n 的取值**：默认 n=10（展示清晰），提供切换按钮（10 / 20 / 50 / 100）
- **方块尺寸**动态适配 Canvas 尺寸
- 每个方块有极细边框 + 半透明填充，保持科技感
- 构建阶段方块带"生长"动画（从 y=底边 上升到 最终位置）
- 镜像使用 `globalAlpha` + 渐变实现半透明效果

## 5. 交互与控制
- 播放/暂停按钮
- 进度条（Range Slider），支持手动拖拽
- n 值选择器（10 / 20 / 50 / 100），切换时重置动画
