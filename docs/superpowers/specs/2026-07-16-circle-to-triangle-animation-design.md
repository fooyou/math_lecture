# 设计文档：圆面积逼近几何动画 (写实科技风)

## 1. 概述
本动画旨在通过写实科技风的几何形变，向小学生直观展示将圆的面积转换为等腰三角形面积的近似计算逻辑。动画重点在于严谨、流畅的几何形变，摒弃不必要的流体波动特效。

## 2. 视觉风格
- **背景**：深色调（深空灰/藏青），营造高科技精密实验室感。
- **几何线条**：冷色调（科技蓝/极光绿），带轻微辉光，模拟精密设备激光切割或投影效果。
- **标注**：极简现代字体，白色或与线条同色，清晰可见。

## 3. 动画环节
1. **初始态**：
   - 画面中心呈现由细密同心圆构成的圆。
   - 圆心为微小的发光能量核心。
2. **形变过程**：
   - 圆心能量核心放射出一条半径线，作为形变基准。
   - 圆周轨迹线按半径顺序，由外向内（或由圆周展开）平滑线性平铺，向下延展。
   - 上层圆轨迹逐渐收缩，汇聚于圆心上方（形成三角形顶角）；底层圆轨迹保持长度，铺开构成三角形底边。
   - 动画过程保持几何精度，无水波纹等视觉干扰。
3. **最终态**：
   - 圆完全转化为一个等腰三角形。
   - 底边高亮，标注为 `Base = 2πr`。
   - 垂直高度线高亮，标注为 `Height = r`。
   - 动态演化出公式推导：`Area = (1/2) * (2πr) * r = πr²`。

## 4. 交互与节奏
- 节奏应当匀速、稳健，确保小学生能看清逻辑演变。
- 动画完成后静止 2 秒，以便观众查看最终推导公式。
