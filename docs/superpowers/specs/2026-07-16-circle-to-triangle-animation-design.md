# 设计文档：圆面积逼近几何动画 (写实科技风)

## 1. 概述
本动画旨在通过写实科技风的几何形变，向小学生直观展示将圆的面积转换为等腰三角形面积的近似计算逻辑。动画重点在于严谨、流畅的几何形变，通过将同心圆断开并线性平铺至水平位置，直观呈现面积转换。

## 2. 视觉风格
- **背景**：深色调（深空灰/藏青），营造高科技精密实验室感。
- **几何线条**：冷色调（科技蓝/极光绿），带轻微辉光，模拟精密设备激光切割或投影效果。
- **标注**：极简现代字体，白色。

## 3. 动画环节
1. **初始态**：
   - 画面中心呈现细密、高亮显示的同心圆结构。
   - 包含从圆心垂直向上的半径标注 `r`，以及圆心能量核心。
2. **形变过程 (线性平滑展开)**：
   - 同心圆从外向内逐层“断开”。
   - 已断开的圆周线平滑平铺为对应高度的水平线段（高度 y = cy + r，线段长 2πr）。
   - 随着展开过程，三角形的两条腰线从底边两端点同步向上方圆心顶点生长延伸。
   - 已展开的圆圈以极低透明度的“幽灵线”形式保留，以直观对比圆周与平铺线段的几何关系。
3. **最终态**：
   - 形成底边为 `2πr`、高为 `r` 的等腰三角形框架，顶点位于原圆心。
   - 底部显示面积推导公式：`面积 Area = 1/2 * 底边 * 高 = πr²`。

## 4. 交互与控制
- 提供播放/暂停按钮。
- 提供进度条（Range Slider），支持手动拖拽控制动画进度。

## 5. 本地化
- UI 及标注文字均使用中文描述（如“底边 Base”、“高 Height”）。
