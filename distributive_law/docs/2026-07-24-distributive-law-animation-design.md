# 设计文档：乘法分配律可视化动画 (矩形面积模型)

## 1. 概述
本动画通过**矩形面积的分割与合并**直观展示乘法分配律 `a × (b + c) = a × b + a × c`。核心思路：一个大矩形可以被分割成两个小矩形，它们的面积之和等于大矩形的面积。

## 2. 视觉风格
- **背景**：深色 `#010204`，延续现有项目的科技风格。
- **完整矩形**：青色半透明填充。
- **左半部分 (a×b)**：青色填充。
- **右半部分 (a×c)**：金色填充。
- **分割线**：白色虚线动画。
- **KaTeX 公式**：黄色高亮，右侧面板显示。

## 3. 动画环节

### 第1阶段：完整矩形出现 (progress 0.00 – 0.15)
- 画布中央绘制一个大矩形（宽=a，长=b+c）。
- 标注宽=`a`，长=`b+c`。
- 文字提示："矩形面积 = a × (b+c)"。

### 第2阶段：分割线出现 (progress 0.15 – 0.35)
- 一条竖线从上到下"切割"矩形。
- 分割线用白色虚线表示，带发光效果。
- 矩形被分成左右两部分。

### 第3阶段：面积标注 (progress 0.35 – 0.55)
- 左半部分填色为青色，标注面积 `a×b`。
- 右半部分填色为金色，标注面积 `a×c`。
- 两个面积值高亮显示。

### 第4阶段：合并等式 (progress 0.55 – 0.75)
- 分割线闪烁，两侧面积值同时高亮。
- 显示等式：`a×(b+c) = a×b + a×c`。
- 数值验证：代入具体数字计算。

### 第5阶段：公式总结 (progress 0.75 – 1.00)
- KaTeX 公式逐步显示：
  ```
  a × (b + c) = a × b + a × c
  例：3 × (4 + 5) = 3 × 4 + 3 × 5 = 12 + 15 = 27
  ```
- 最终公式高亮。

## 4. 技术实现要点

### 坐标系统
- 矩形中心对准画布中心。
- 尺寸根据画布尺寸自适应。
- 宽度 a 和长度 b+c 按比例缩放。

### 矩形绘制
- 使用 `ctx.fillRect` 绘制填充矩形。
- 使用 `ctx.strokeRect` 绘制边框。
- 分割线用 `ctx.setLineDash` 虚线。

### 分割动画
- 分割线位置用 `lerp` 从左到右移动。
- 两个小矩形的宽度随分割线位置动态变化。

### 数值选择器
| a | b | c | 等式 |
|---|---|---|------|
| 3 | 4 | 5 | 3×(4+5) = 3×4 + 3×5 = 27 |
| 2 | 3 | 6 | 2×(3+6) = 2×3 + 2×6 = 18 |
| 4 | 2 | 3 | 4×(2+3) = 4×2 + 4×3 = 20 |

### 交互控制
- 播放/暂停按钮（右上角）。
- 进度条（右上角），支持拖拽。
- 数值选择器，切换时重置动画。

│         [3×(4+5)] [2×(3+6)] [4×(2+3)]      │ ← 数值选择器
│                                              │
│              ┌─────────────────┐             │
│              │    a×b    │ a×c │             │
│              │   (青色)  │(金色)│             │

│    ┌──────────────────────────────┐          │

## 6. 公式 (KaTeX)
```latex
a \times (b + c) = a \times b + a \times c
\text{例：} 3 \times (4 + 5) = 3 \times 4 + 3 \times 5 = 12 + 15 = 27
```

## 7. 本地化
- UI 及标注文字均使用中文。
- KaTeX 公式中出现的文字标注使用 `\text{}`。
