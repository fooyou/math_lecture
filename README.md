# 数学趣味讲解

用有趣的思路解数学问题，帮助初学者掌握数学思维。

## 项目理念

数学不应该只是枯燥的公式和计算。本项目通过**可视化动画**和**直观的思路**，让抽象的数学概念变得生动易懂。每个讲解都注重：

- **直觉优先**：先建立直观理解，再推导公式
- **趣味驱动**：用有趣的视角重新审视经典问题
- **思维培养**：不仅教"怎么做"，更教"怎么想"

## 当前内容

### 1. 圆变三角形 - 圆面积公式的直观推导

将圆"展开"成三角形，一眼看懂为什么圆面积是 πr²。

**核心思路**：把圆看成无数个同心圆环的叠加。当这些圆环被"断开"并"平铺"时，它们自然形成一个三角形：
- 三角形的底边 = 圆的周长 = 2πr
- 三角形的高 = 圆的半径 = r
- 三角形面积 = ½ × 底 × 高 = ½ × 2πr × r = πr²

**运行方式**：
```bash
# 直接在浏览器中打开
open circle_to_triangle/index.html
```
