# 设计文档：分数加减法可视化动画 (扇形模型)

## 1. 概述
本动画通过**圆形扇形的分割、通分、合并**直观展示分数加法的计算过程。核心思路：用扇形面积表示分数，通过通分将不同分母的分数转换为同分母，再合并计算。

## 2. 视觉风格
- **背景**：深色 `#010204`，延续现有项目的科技风格。
- **第一个分数扇形**：青色填充。
- **第二个分数扇形**：金色填充。
- **合并后扇形**：青色+金色叠加显示。
- **通分高亮**：白色闪烁。
- **约分高亮**：白色边框。
- **KaTeX 公式**：黄色高亮，右侧面板显示。

## 3. 动画环节

### 第1阶段：显示第一个分数 (progress 0.00 – 0.15)
- 画布左侧出现一个圆形。
- 扇形区域用青色填充，表示第一个分数（如 1/3）。
- 标注分数值。

### 第2阶段：显示第二个分数 (progress 0.15 – 0.30)
- 画布右侧出现第二个圆形。
- 扇形区域用金色填充，表示第二个分数（如 1/6）。
- 标注分数值。

### 第3阶段：通分动画 (progress 0.30 – 0.55)
- 两个圆的扇形细分线同时变化。
- 第一个分数 1/3 → 2/6（扇形重新着色）。
- 显示通分过程：分子分母同时乘以2。

### 第4阶段：合并结果 (progress 0.55 – 0.75)
- 两个同分母扇形合并到一个圆中。
- 显示 2/6 + 1/6 = 3/6。
- 扇形区域用叠加颜色显示。

### 第5阶段：约分 (progress 0.75 – 0.90)
- 3/6 的扇形高亮。
- 约分线出现，变为 1/2。
- 显示约分过程：分子分母同时除以3。

### 第6阶段：公式总结 (progress 0.90 – 1.00)
- KaTeX 公式逐步显示：
  ```
  1/3 + 1/6 = 2/6 + 1/6 = 3/6 = 1/2
  通用公式：a/b + c/d = (ad+cb)/(bd)
  ```

## 4. 技术实现要点

### 坐标系统
- 两个圆并排显示，中心对准画布中心。
- 圆的半径根据画布尺寸自适应。

### 扇形绘制
- 使用 `ctx.arc()` 绘制扇形路径。
- 使用 `ctx.fill()` 填充扇形区域。
- 扇形角度 = 分数值 × 360°。

### 通分动画
- 用 `lerp` 控制扇形数量从原分母渐变到公分母。
- 通分时扇形边界线逐条出现。

### 约分动画
- 约分时扇形区域高亮。
- 显示约分后的分数值。

### 分数选择器
| 分数1 | 分数2 | 公分母 | 结果 |
|-------|-------|--------|------|
| 1/3 | 1/6 | 6 | 1/2 |
| 1/4 | 1/3 | 12 | 7/12 |
| 2/5 | 1/10 | 10 | 1/2 |

### 交互控制
- 播放/暂停按钮（右上角）。
- 进度条（右上角），支持拖拽。
- 分数选择器，切换时重置动画。

## 6. 公式 (KaTeX)
```latex
\frac{1}{3} + \frac{1}{6} = \frac{2}{6} + \frac{1}{6} = \frac{3}{6} = \frac{1}{2}
\frac{a}{b} + \frac{c}{d} = \frac{ad + cb}{bd}
```

## 7. 本地化
- UI 及标注文字均使用中文。
- KaTeX 公式中出现的文字标注使用 `\text{}`。
